# Forced retry requires the initiating committed lease

This correction starts from `8b803c2c66f3f2d3a68d65725e309de314712dc0`, preserving its certificate requirement and bounded retired-token history, together with `df75411f` and earlier close repairs.

Both independently reported forced-retry orderings reproduced before editing with the actual registry and extracted patched Chromium methods under ASan/UBSan. Restarting the same manager while Begin waited, or withdrawing Chromium's ignore-unload policy during that wait, closed tabs with native begin still false and the attempt cancellable. The reproduction source and before/after logs are `/tmp/ardia-close-forced-retry/probe.py`, `before.log` and `after.log`.

Forced Begin and Destroy continuations now capture the initiating nonempty token after preparation. Before either cancellation or destruction, they compare it with the current token on the original weak browser. First forced destruction additionally requires the same attempt to be irreversible. A live manager and a readiness `true` alone cannot grant that authority. Empty-token callbacks and callbacks from earlier attempts cannot adopt a newer committed lease; ordinary synchronous null-hook and unhosted forced shutdown remain available.

A current, uncommitted retry clears the force-skip flag and returns through the manager's policy-selected preparation path. Withdrawing ignore-unload therefore runs the real beforeunload handlers and allows their veto. Restarted or overlapping current managers retain their participation; expired manager retries are discarded. After actual commitment, the exact same attempt can finish Destroy despite manager invalidation or later policy withdrawal. Token and cancellation state are rechecked around reentrant/destructive boundaries, while accepted Begin still reaches its first destructive action in the same UI task. New windows receive their own preparation.

The public two-pointer ABI, four native helpers and internal admission API are unchanged by this correction. No registry, native-host, JS, dependency, GN, manifest or source-cache files changed.
